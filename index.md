# YouTube API LINE Monitor

Welcome to the YouTube API LINE Monitor project page.

## About This Project

YouTube API LINE Monitor is a personal monitoring tool that checks whether the owner's authorized YouTube Data API connection is working and sends LINE notifications when the monitoring status changes.

## Features

- Checks access to the authorized YouTube channel.
- Detects changes in API monitoring status.
- Sends status notifications through LINE.
- Runs scheduled checks on the owner's computer.

## Privacy

This application uses Google OAuth to access authorized YouTube channel information and LINE messaging services to deliver notifications.

For details about information access, storage, and handling, please read our [Privacy Policy](privacy.html).
