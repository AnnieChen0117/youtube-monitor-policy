# Privacy Policy — YouTube API LINE Monitor

**Last updated: October 26, 2026**

## 1. Overview

YouTube API LINE Monitor is a personal application that checks the status of the owner's authorized YouTube API connection and sends status notifications through LINE.

## 2. Information Accessed

With the owner's authorization, the application uses the YouTube Data API to retrieve basic information about the authorized YouTube channel, such as its channel name.

The application also uses OAuth credentials and tokens to maintain authorized access to the API.

## 3. How Information Is Used

Information is used to:
- Check whether the authorized YouTube API connection is working.
- Detect changes in monitoring status.
- Send relevant status notifications to the owner's LINE account.

The application is not intended to sell personal information or use it for advertising.

## 4. Storage and Sharing

OAuth credentials, configuration settings, and monitoring state are stored in the owner's local project environment.

When a notification is sent, the relevant message is transmitted through LINE's messaging services and is subject to LINE's applicable terms and privacy policy.

The application is not intended to share YouTube channel information with unrelated third parties.

## 5. Data Retention and Deletion

The owner may delete local monitoring state files and revoke the application's Google account authorization when access is no longer needed.

## 6. Security

OAuth client secrets, access tokens, refresh tokens, and LINE channel access tokens should be kept private and must not be published in this repository.

## 7. Third-Party Services

This application uses Google OAuth, the YouTube Data API, and LINE messaging services.

- Google Privacy Policy: https://policies.google.com/privacy
- YouTube Terms of Service: https://www.youtube.com/t/terms
- LINE Privacy Policy: https://line.me/en/terms/policy/

## 8. Contact

For questions about this application or this privacy policy, contact the application owner through the contact information provided in the associated Google OAuth application settings.
